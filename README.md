# Wednesday 25 November 2026: 34 stories, 10 regions

One front page summing up Wednesday 25 November 2026 in a single image:
a navy masthead naming the day, a lead story on the Houthi missile
strike on Riyadh with a drawn scene, a red DATE CHECK box holding back
stories first reported before the day (COP31 Antalya collapse, Sinner's
knee surgery, the Panahi sentence, the Hong Kong tower-block fire), and
33 more stories across 10 regions and 14 fields — each with a one-line
label, a dateline, a UTC time and a sourcing label (OFFICIAL / CONFIRMED
/ REPORTED / CLAIM). A schematic pin map, a UTC timeline and a markets
strip close the page. All art is drawn shapes; there are no photos.

Every story was first reported on 25 November 2026 (any time zone) and
cross-checked against at least two sources: Reuters, AP, Eurostat,
Principia, Open Chronicle, RadioFree, WebIndia123 and HRANA.

## Run it

```sh
python3 build.py   # renders entry.png (1024x1024, under 1 MiB)
node main.ts       # copies entry.png to $MAKEFUN_OUTPUT_DIR/entry.png
```
